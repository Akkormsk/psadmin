ГосПлан используется только для discovery по первичному фильтру PROD; один collector передаёт исходные карточки в обе независимые БД. TEST не получает отдельную долю API-квоты и не дублирует запросы. Совместимые secondary функции делегируют прямому XML-адаптеру ЕИС; публичное чтение протоколов уже было прямым. Извещения нормализуются в прежний `source`-контракт; неподтверждённый/отсутствующий раздел не очищает кэш. ЕИС код 34 запускает локальную приостановку повторов (`EIS_ACCESS_BLOCK_RETRY_SECONDS`, default 3600), токен в сообщениях скрывается. Это не подтверждает снятия блокировки и не доказывает полноту ЕИС.

Ограничения: PRIZ XML-архивы, все виды документов/разъяснений/жалоб и точность нормализации требуют реальной приёмки после восстановления ПМД. Если раздел жалоб отсутствует в пакете, возвращается ошибка полноты, а не «жалоб нет». Отдельный реестр контрактов и широкая историческая выборка статистики ещё не имеют подтверждённой прямой замены: новые обращения туда не выполняются; сохранённая статистика остаётся. Карточки организаций пока переиспользуются из извещений. Эти части не объявлять работающими по предположению.
