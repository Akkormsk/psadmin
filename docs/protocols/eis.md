### Прямой ЕИС: адрес сервиса и блокировка ПМД — 2026-11-12

DECIDED_BACKLOG, уточнение владельца 2026-11-12: готовить перенос secondary запросов на ЕИС несмотря на блокировку ПМД. ГосПлан используется только для discovery по первичному фильтру PROD; один collector передаёт исходные карточки в обе независимые БД. TEST не получает отдельную долю API-квоты и не дублирует запросы. Суточная проверка покрытия — отдельное наблюдение, не блокирующее реализацию и не меняющее настройки автоматически. ЕАТ остаётся следующим отдельным этапом.

Ветка `feature/discovery-eis-mirror` от актуального TEST `5a9ad7f` с изолированным исправлением EIS endpoint. Deploy этой реализации ещё не подтверждён; PROD не менялся. `gosplan._get` разрешает только GET списков fz44/fz223 purchases. Совместимые secondary функции делегируют прямому XML-адаптеру ЕИС; публичное чтение протоколов уже было прямым. Извещения нормализуются в прежний `source`-контракт; неподтверждённый/отсутствующий раздел не очищает кэш. ЕИС код 34 запускает локальную приостановку повторов (`EIS_ACCESS_BLOCK_RETRY_SECONDS`, default 3600), токен в сообщениях скрывается. Это не подтверждает снятия блокировки и не доказывает полноту ЕИС.

Ограничения: PRIZ XML-архивы, все виды документов/разъяснений/жалоб и точность нормализации требуют реальной приёмки после восстановления ПМД. Если раздел жалоб отсутствует в пакете, возвращается ошибка полноты, а не «жалоб нет». Отдельный реестр контрактов и широкая историческая выборка статистики ещё не имеют подтверждённой прямой замены: новые обращения туда не выполняются; сохранённая статистика остаётся. Карточки организаций пока переиспользуются из извещений. Эти части не объявлять работающими по предположению.
