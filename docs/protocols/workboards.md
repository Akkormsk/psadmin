# Доски и исполнение

## M2.2 — CODE_ONLY

Ветка feature/workboards. Рабочая позиция сохраняет существующую таблицу, PK и связи. Добавлены Task и варианты владельца Order/Task; ограничение БД требует ровно одного владельца и запрещает тендерное задание для нетендерной позиции. Уникальность source_key сохраняется отдельно по владельцу. Проверка принадлежности job и source_items выполняется при обычном ORM save и M2M add (включая обратную связь); прямые SQL, bulk/update и запись в промежуточную таблицу не обеспечивают проверку межтабличной принадлежности. Не использовать их для смены владельца или источников без специальной проверки.

Компоненты, маршруты, этапы, расчёты, UI и обработка тендеров не меняются. Миграция добавочная, данные не удаляются. Следующий этап после проверки — универсализация компонентов. TEST/PROD не развёрнуты. Проверки CI выделены в workflow feature/workboards; результаты фиксируются отдельно.
