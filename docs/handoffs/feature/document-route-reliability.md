# Goal
Исправить распознавание документов, привязку сведений к товарам и построение предварительных маршрутов до завершения M2 UI/UX. Ветка создана от `feature/tender-card-uiux` на коммите `01ed4f9`.

# Completed
В родительской ветке уже реализован устойчивый приём ответов ИИ: подтверждённые сведения сохраняются, неясные остаются отдельно, ошибка одного товара не должна блокировать остальные. Предварительные маршруты используют доступные сведения из извещения и документов; сохранённые маршруты переиспользуются по полному отпечатку входных данных. Исправления проверялись 76 целевыми тестами и локальным повтором сохранённых данных 7 тендеров без платных вызовов.

# Current State
Нужно подтвердить поведение на актуальном коде `test-server`, который уже ушёл вперёд относительно родительской ветки. Предыдущая попытка доставки `01ed4f9` была остановлена серверными тестами: 143 из 146 прошли. Остались три расхождения: офлайн-тест маршрута зависел от каталога моделей; тест готового расчёта ожидал общий отказ вместо изоляции товара; тест истории предложений ожидал прежнее архивирование всех предложений. Эти случаи нельзя закрывать простой сменой ожиданий — нужно сверить сохранность расчётов и истории.

Исходная проблема тендера `0172200010426000028`: сохранённый ответ использовал одиночную ссылку на товар и содержал неопределённые фрагменты; текущие маршруты отсутствовали, два старых маршрута сохранились без надёжной связи с товарами. Не привязывать их по одинаковому названию и не выдавать за актуальные.

# Next Step
Сначала совместить ветку с актуальным `origin/test-server` и повторно проверить три серверных сбоя без платных вызовов. Затем отдельными этапами: 1) сохранённые успешные и неуспешные ответы чтения/сопоставления; 2) изоляция ошибок товаров и перестроение только затронутых маршрутов; 3) доступ к старым маршрутам с пометкой истории; 4) согласованный деплой на TEST и ограниченная проверка реальных тендеров. После приёмки вернуться в `feature/tender-card-uiux` и продолжить M2.
