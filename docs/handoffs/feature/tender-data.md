# Completed
Общая архитектура, прямой ЕИС, устранение равных копий наборов, сохранность истории доставлены. Верхний toast копирования; пунктир только в основной информации; спокойный 1875; статус чтения независим от stale риск-оценки.
Системное правило названия в промпте: краткое имя из источников, характеристики/изготовление в ТЗ, без товарных словарей. Модель получает принятые части и их ТЗ, возвращает явный accepted_source_item_id; backend проверяет принадлежность/уникальность и не сопоставляет по имени. Принятые факты сохраняются при пропусках, draft не заменяет принятую карточку. Одинаковые значения обычным цветом, новые синим; отдельной строки/правила для количества нет. Отклонённые отдельные цитаты только в диагностике; реальная ошибка разбора объясняет сохранность данных и следующий шаг.
