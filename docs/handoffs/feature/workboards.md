# Scope boundaries
Маршруты/этапы, финансы, UI, фоновая обработка, источники тендеров, Hermes и контрагенты не изменяются в M2.3. Ближайший MVP досок не включает Order, лиды, сроки, автоматические признаки ожидания/действия, результаты/обучение или юридическое закрытие Tender. При бизнес-неясности спросить владельца. Никакого хардкода, дублирования или удаления старых сущностей без доказанной замены.
