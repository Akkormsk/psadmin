# Scope boundaries
Ближайший MVP досок не включает Order, лиды, сроки, автоматические признаки ожидания/действия, результаты/обучение или юридическое закрытие Tender. При бизнес-неясности спросить владельца. Никакого хардкода, дублирования или удаления старых сущностей без доказанной замены.
