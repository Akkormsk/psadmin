# Goal
Завершить M2.3: редактировать единый перечень и себестоимость прямо во вкладке «Товары» карточки тендера. Прежний «Расчёт товаров» остаётся для Orders; отдельное приложение «Калькулятор» вне задачи.

# Completed
Реализованы спокойный просмотр и отдельный режим редактирования: товары, количество, единица, НМЦК, группы, состав, добавление и исключение. Себестоимость поддерживает общую ручную сумму, детализацию и сохранённый маршрут. Ручная цена имеет приоритет; маршрут сохраняется для возврата. Есть сохранение, отмена, предупреждение о несохранённом и защита от фоновой замены черновика.

Рабочие товары и компоненты имеют стабильные связи; исходники не изменяются. Каждое сохранение создаёт новую версию расчёта, сохраняет историю и помечает зависимые результаты устаревшими. Составные товары считаются по компонентам, их общий результат показывается в строке товара.
