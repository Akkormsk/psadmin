## DECIDED_BACKLOG — реализовать согласованное, не обсуждать повторно
1. Тендер имеет фиксированный исходный набор товаров. Убрать кнопки общего редактора, добавления, удаления/исключения; сервер также не должен позволять произвольное изменение количества, НМЦК, состава через этот редактор. Принятие доказанных правок ТЗ/разбор наборов остаются. Заказы сохраняют полноценное редактирование; общие компоненты с разрешёнными действиями, без лишних условных интерфейсов.
2. Единственная обычная ручная правка товара — внутреннее переименование: маленький карандаш при наведении на имя внутри открытой карточки, доступный также без hover. Сохранить исходное имя и стабильную идентичность; alias не должен менять вход маршрутизатора или инвалидировать расчёт. Не использовать общее save_products для произвольных изменений по HTTP.
3. Закрытый этап: название, цена за тираж и за единицу. Раскрытый: исполнитель, способ получения цены, краткая сводка автоматического расчёта. Если не выбран/не рассчитано — честные пустые значения. В правом нижнем углу раскрытого этапа маленький карандаш «Указать цену вручную», даже без контрагента. Форма скрыта до клика: компактный сегмент unit/total (не select), сумма, предварительный пересчёт, сохранить/отмена. После сохранения источник «Ручной ввод», возможность изменить/вернуться к автоматическому. Никакой отдельной кнопки подбора исполнителя сейчас.
4. Автоматический расчёт — default. Одна действующая цена на этап независимо от источника (API/калькулятор/прайс/ручной ввод). Ручная цена не перезаписывается фоном; возврат к авто восстанавливает только актуальный подтверждённый результат, иначе неизвестно. Карточка показывает результат и ручную цену; ассистент корректирует маршруты, подбирает исполнителей, обучает систему. Если маршрут вообще отсутствует, позднее предусмотреть ручное формирование из существующих этапов (один этап допустим), не вводить себестоимость вне маршрута.
5. НМЦК из извещения, прогнозное снижение до торгов, фактическая цена после торгов. Себестоимость только сумма этапов; неизвестно != 0. История прежних цен сохраняется, не распределять старую общую цену произвольно между этапами. Заказы не ломать.
