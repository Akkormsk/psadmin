## Goal
Получать полную доступную выдачу ГосПлана по управляемым фильтрам; первичный отбор только у источника, разовый минус-отсев — в общий архив. Измерить число актуальных закупок и реальные затраты запросов, затем свериться с девятью этапами из протокола.
